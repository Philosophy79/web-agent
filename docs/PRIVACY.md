# 隐私与数据说明（PRIVACY）

web-agent 以**本地处理**为设计原则：你提供什么、工具处理什么，数据全部留在你自己的电脑上。

## 数据流一览

| 数据 | 去向 |
| --- | --- |
| 网页内容读取（fetch/shot/open/act） | 只在你本机浏览器与终端之间流动，不上传 |
| 视频转录（video/media） | 视频/音频下载到本地 `downloads/`，转录由本地 Whisper 模型完成；转录完成后原始素材自动删除 |
| 识图（vision ocr/describe） | 图片只在本地处理；视觉服务仅监听 `127.0.0.1`，本机以外无法访问；OCR 与视觉大模型均本地运行 |
| 桌面控制（desktop） | 仅操作本机界面，截屏文件保存在本地 `output/` |
| 操作日志 | 仅写入本地 `logs/agent.log`，不会上传；**不会记录账号密码** |

## 账号与 Cookie

- 需要登录的网站：登录页在可见浏览器窗口中打开，**密码由你本人输入**，工具不接触、不保存密码
- 个别站点下载需要"新鲜 Cookie"（仅访问页面即可获得，无需登录）：工具会用你本机浏览器
  临时采集一次，**使用完毕立即自动删除**；下次使用会重新采集
- 不读取、不上传你的浏览器历史记录、书签或已保存的密码

## 网络请求何时发生

工具本身**不联网**，仅在你主动触发以下动作时产生网络请求：

1. 你明确给出 URL 让工具读取/下载时，访问该目标站点
2. 首次安装时，从公开镜像源下载依赖与模型文件：
   npm 官方源、PyPI 及国内镜像、hf-mirror.com、ghfast.top（GitHub 加速）、ModelScope
3. 视频转录时访问你指定的视频平台页面

所有请求均为"拉取"，**没有任何数据上传行为**。

## 删除数据

- 每次视频转录完成自动清理中间产物，只保留 `transcript.txt` / `transcript.srt`
- `node agent.mjs cleanup` 可手动清扫全部临时残留
- 卸载：直接删除本目录即可，无注册表项、无后台服务残留
  （常驻的视觉服务可用 `node agent.mjs vision describe --stop` 关闭）

## 隐私保护建议（给使用者）

- 不要转录、截屏或保存包含他人个人信息（身份证号、手机号、住址等）的内容
- 处理后的资料如需分享，请先脱敏
- 多用户共用电脑时，建议各自使用独立目录
