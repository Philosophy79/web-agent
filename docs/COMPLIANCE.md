# 使用条款与合规边界（COMPLIANCE）

web-agent 是通用浏览器自动化与媒体下载工具，**只应被用于合法目的**。
下载、安装或使用本项目即表示你同意本条款。

## 一、允许的用途

- 处理你**有权访问**的公开网页内容或你自有账号下的内容，用于个人学习、研究、笔记整理
- 自动化你自己的工作流程（填表、下载资料、截图存档等）
- 将视频转录为文字，供个人学习使用

## 二、禁止的用途

依据《中华人民共和国网络安全法》《中华人民共和国个人信息保护法》
《中华人民共和国著作权法》等法律法规，禁止将本项目用于：

1. **未经授权**访问计算机信息系统，或绕过访问控制（付费墙、登录墙、验证码、
   DRM 数字版权保护等）获取无权访问的内容
2. **批量采集、买卖、泄露公民个人信息**（如身份证号、手机号、住址、人脸等）
3. 对目标网站发起高频请求，影响其正常运行或服务质量
4. 下载、传播受著作权保护的作品并用于商业用途或公开分发（转录稿仅限个人学习）
5. 任何形式的诈骗、侵权、造谣传谣、危害网络安全的活动

## 三、使用规范

- 遵守目标网站的 **robots.txt** 协议与服务条款（ToS）
- 控制请求频率，必要时使用 `--wait` 参数降低抓取速度
- 处理含他人个人信息的内容后，分享前应进行脱敏
- 使用桌面控制功能时，只操作你自己的电脑与账户
